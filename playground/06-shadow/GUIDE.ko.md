## 0. 왜 이걸 하는가

5단계까지는 "표면이 광원 쪽을 향했나"만 봤습니다. **사이에 뭐가 가로막고 있는지는 안 봤어요.** 그래서 물체 뒤쪽 면도 각도만 맞으면 환하게 빛납니다.

그림자는 개념적으로 놀랄 만큼 단순합니다:

> 교차점에서 광원 쪽으로 **광선을 하나 더 쏴본다. 뭔가 맞으면 그늘이다.**

이게 **2차 광선(secondary ray)**입니다. 코드 양은 적은데, 여기서 배우는 것 — "교차 판정 함수를 재사용한다", "epsilon으로 자기 자신을 피한다" — 는 계속 쓰입니다.

---

## 1. 배울 개념

### (1) 그림자 광선

```
origin    = 교차점 P
direction = normalize(광원 - P)
```

이 광선으로 **모든 도형에 대해 교차 판정**을 다시 돌립니다. 4단계에서 만든 `hit_sphere`를 그대로 재사용합니다.

### (2) 거리 비교 — 빠뜨리기 쉬움

"뭔가 맞았다"만으로는 부족합니다. **광원보다 멀리 있는 물체는 그림자를 만들지 않습니다.**

```
light_distance = length(광원 - P)
그림자다  ⟺  0 < t < light_distance 인 교차가 존재
```

방향을 정규화했다면 `t`가 곧 거리라서 그냥 비교하면 됩니다. **3단계에서 정규화를 강조한 이유가 여기 있습니다.**

### (3) 그림자면 diffuse를 0으로

```
color = ambient                        /* 그늘 */
color = ambient + diffuse              /* 빛 받음 */
```

**ambient는 남깁니다.** 그림자가 완전한 검정이 되면 안 됩니다.

### (4) 그림자 여드름 (shadow acne) — 이 단계의 주인공

교차점 `P`에서 광선을 쏘면, **그 광선이 자기가 서 있는 그 표면을 t≈0에서 다시 맞습니다.** 부동소수점 오차 때문에 `P`가 표면에서 아주 미세하게 안쪽에 있을 수 있거든요.

증상: **표면 전체에 지저분한 검은 점무늬 얼룩.** 처음 보면 "왜 이렇게 노이즈가 끼지" 싶습니다.

해결은 둘 중 하나 (또는 둘 다):

```
1) t_min을 1e-4 로 두고 그보다 가까운 교차는 무시     ← 권장
2) 광선 시작점을 법선 방향으로 살짝 밀기: P + n * 1e-4
```

4단계에서 `t_min`을 넣어뒀다면 이미 반쯤 해결돼 있습니다.

**epsilon이 너무 크면** 얇은 물체가 그림자를 못 만들고, **너무 작으면** acne가 남습니다. `1e-4` 근처면 무난합니다.

## 2. 구현 순서

- [ ] **1. `in_shadow(scene, P, light)` 작성** — 광선 만들고 모든 도형 순회, `t_min < t < light_distance` 교차가 하나라도 있으면 참
- [ ] **2. 조명 계산에 연결** — 그늘이면 diffuse 생략
- [ ] **3. 구 두 개** — 하나가 다른 하나를 가리게 배치. **뒤 구에 그림자가 지면 성공**
- [ ] **4. acne 관찰 (일부러)** — epsilon을 0으로 바꿔보고 얼룩을 직접 보세요. 나중에 실제로 만났을 때 바로 알아봅니다
- [ ] **5. 광원 뒤 물체** — 광원보다 먼 곳에 구를 놓고, 그림자가 **안 생기는지** 확인. 거리 비교를 빠뜨렸으면 여기서 걸립니다

## 3. 함정

**첫 교차에서 바로 끝내기 — 이건 오히려 최적화입니다.** 그림자 판정은 "가장 가까운 것"을 찾을 필요가 없습니다. **뭐라도 하나 걸리면 즉시 참을 반환**하세요. 카메라 광선과 다른 점입니다.

**거리 비교 누락** → 광원 뒤의 물체가 그림자를 만듭니다. 화면 구석에 설명 안 되는 어두운 영역이 생깁니다.

**정규화 안 함** → `t`가 거리가 아니라서 거리 비교가 무의미해집니다. 그림자가 나오다 말다 합니다.

**ambient까지 0으로** → 그림자가 새까매집니다. 부자연스럽고 subject와도 안 맞습니다.

**자기 자신을 세는 epsilon 문제** → acne.

**검사 7개** — 표면점은 원점, 광원은 `(0,10,0)`:
