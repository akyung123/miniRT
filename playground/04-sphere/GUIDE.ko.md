## 0. 왜 이걸 하는가

앞으로 나올 모든 교차 판정이 똑같은 틀입니다:

```
도형의 방정식에 P(t) = A + tb 를 대입 → t에 대해 푼다
```

구가 그중 가장 단순하고, 여기서 나온 2차방정식 풀이가 **8단계 원기둥에서 거의 그대로 재사용**됩니다. 그러니 이번엔 공식을 외우지 말고 **직접 전개해보세요.** 그래야 원기둥에서 혼자 할 수 있습니다.

## 1. 수식 유도

### 구의 정의

중심 `C`에서 거리가 `r`인 점들의 집합:

```
|P - C| = r        →        dot(P - C, P - C) = r²
```

### 대입

`P = A + tb`를 넣고, `oc = A - C`로 두면:

```
dot(oc + tb, oc + tb) = r²
```

전개하면 (dot은 분배법칙이 성립합니다):

```
t² · dot(b,b) + 2t · dot(b,oc) + dot(oc,oc) - r² = 0
```

즉 `at² + bt + c = 0`이고:

```
a = dot(dir, dir)          /* dir이 단위벡터면 = 1 */
b = 2 * dot(dir, oc)
c = dot(oc, oc) - r²
```

**이 전개를 종이에 한 번 직접 해보세요.** 5분이면 됩니다.

### 판별식

```
D = b² - 4ac
```

| D | 의미 |
|---|---|
| < 0 | 안 맞음 |
| = 0 | 스치듯 접함 |
| > 0 | 뚫고 지나감 (교차점 2개) |

### 근

```
t = (-b ± sqrt(D)) / (2a)
```

**두 근 중 가장 작은 양수 t**를 고릅니다.

- 둘 다 음수 → 도형이 카메라 **뒤**에 있음 → 안 맞은 것으로 처리
- 작은 쪽이 음수, 큰 쪽이 양수 → 카메라가 도형 **안**에 있음 → 큰 쪽 사용

실무적으로는 `t_min = 1e-4`, `t_max = 무한대` 범위를 두고 그 안에 드는 근만 받습니다. 이 `t_min`이 6단계 그림자 여드름(acne)을 막는 장치가 됩니다. **지금부터 넣어두세요.**

## 3. 함정

### 원이 타원으로 찌그러진다
3단계의 **종횡비 처리를 빠뜨린 것**입니다. `aspect = WIDTH / (double)HEIGHT`.

### 원이 화면 반대쪽에 있다
3단계의 **y축 뒤집기**를 빠뜨린 것입니다.

### 지름 vs 반지름
`.rt` 파일과 파서는 **지름(diameter)**을 줍니다. 9단계에서 씬을 연결할 때 **반드시 `/2`**. 지금은 하드코딩이라 안 걸리지만, 나중에 "구가 두 배로 크다"의 원인이 100% 이겁니다. 지금부터 구조체 필드 이름을 `radius`로 명확히 해두세요.

### 카메라 뒤의 도형이 보인다
`t < 0`을 안 걸렀습니다. 판별식만 보고 "맞았다"고 하면 뒤에 있는 것도 그려집니다.

### `a`를 1로 가정
방향을 정규화했다면 `a = 1`이라 생략해도 되지만, **정규화를 안 한 채로 생략하면 t가 완전히 틀립니다.** 안전하게 `dot(dir,dir)`를 그대로 쓰는 편을 권합니다.

## 4. 최적화 (선택)

`b = 2 * dot(dir, oc)`에서 2를 빼면 (`half_b = dot(dir, oc)`) 판별식이 `half_b² - a*c`로, 근이 `(-half_b ± sqrt(D)) / a`로 간단해집니다. RTIOW가 쓰는 방식입니다. **먼저 원래 공식으로 돌려보고 나서** 정리하세요.
